# Flip Countdown Timer

This project is a simple, visually appealing countdown timer that mimics the style of a mechanical flip clock. It features a smooth flip animation for the digits as the seconds count down.

## Features

- **Flip Animation:** Realistic flip effect for changing numbers.
- **Countdown Functionality:** Counts down from a preset time (default: 24 hours).
- **Controls:**
  - **Start:** Begins the countdown (or resets and starts if already running).
  - **Restart:** Resets the timer and starts the countdown again.
- **Responsive Design:** Centered layout with a dark theme suitable for various screen sizes.

## Technologies Used

- **HTML5:** Structuring the timer and control buttons.
- **CSS3:** Styling the flip segments, animations, and overall layout. Uses CSS variables and Flexbox for positioning.
- **JavaScript (ES6+):** Logic for the countdown timer, updating the DOM elements, and triggering the CSS flip animations.

## Getting Started

To run this project locally, you don't need any build tools or servers.

1.  Clone or download this repository.
2.  Open the `index.html` file in your preferred web browser.

## Project Structure

- `index.html`: The main HTML file containing the structure of the timer.
- `style.css`: Contains all the styles for the flip animation and layout.
- `index.js`: The JavaScript file that handles the countdown logic and DOM manipulation.

## Usage

When the page loads, the countdown will start automatically from 24 hours. You can use the "Start" or "Restart" buttons to reset the timer back to 24 hours at any time.
